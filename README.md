# leaveby-legal

Hosted privacy policy and terms of service for the [Leave By](https://github.com/banksage-max) app, served via GitHub Pages.

- Privacy Policy: https://banksage-max.github.io/leaveby-legal/privacy-policy.html
- Terms of Service: https://banksage-max.github.io/leaveby-legal/terms.html

Source of truth for the underlying policy text lives in the app repo under `store/`; this repo
just hosts the published HTML versions for the app store listings.
